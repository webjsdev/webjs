## Fixes

- **a component's own test does not make a lazy component eager** ([#1551](https://github.com/webjsdev/webjs/pull/1551)) [`842c97b4`](https://github.com/webjsdev/webjs/commit/842c97b4)
  A component's own browser test, which imports it with bindings, no longer
  makes a `static lazy` component eager in the app. Test modules
  (`*.test.*`, `*.spec.*`) never ship to a page, so they do not count.
