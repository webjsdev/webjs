## Fixes

- **`notFound()`, `forbidden()` and `unauthorized()` in an action called over RPC answer 404, 403 and 401** ([#1698](https://github.com/webjsdev/webjs/pull/1698)) [`1824e0eaa`](https://github.com/webjsdev/webjs/commit/1824e0eaa)
  * They answered a logged 500 while the no-JS form path rendered the right status. The generated client stub and `invokeActionForTest` now reject with the same sentinel, so `isForbidden(err)` holds in the caller; with `throwOnError: false` the test gets the body instead.
  * As on the form path, a throw evicts none of the action's declared `invalidates` tags, so a guard at the top of an action cannot be used to flush caches. A `revalidatePath()` the action called before the throw is still reported to the browser.
- **`submitForm` refuses to post a layout's lone logout form** ([#1698](https://github.com/webjsdev/webjs/pull/1698)) [`1824e0eaa`](https://github.com/webjsdev/webjs/commit/1824e0eaa)
  * When the only bound form on the page has no fields and the test submits some, the form the test means is not rendered for that request; `submitForm` now says so instead of signing the user out. A form with fields of its own is still posted.
- **In development, a page POST with no `__webjs_action` field answers a 405 that names the field and `submitForm()`** ([#1698](https://github.com/webjsdev/webjs/pull/1698)) [`1824e0eaa`](https://github.com/webjsdev/webjs/commit/1824e0eaa)
  * Production keeps the bare `Method Not Allowed`.
