## Features

- **`submitForm(..., { html })` and working examples on every WebJs-specific export** ([#1695](https://github.com/webjsdev/webjs/pull/1695)) [`7d949d22f`](https://github.com/webjsdev/webjs/commit/7d949d22f)
  * `submitForm` takes the HTML of a page the test fetched earlier, so a test can submit a stale form (a vote on a poll closed after the page loaded). The "no form found" error names the option.
  * `rateLimit`, `cors`, `clientIp`, `cache`, `revalidateTag`, the file-store helpers, `signedUrl` / `verifySignedUrl`, `broadcast`, the stream helpers, `json`, `readBody`, `route`, `sitemap`, `robots`, `validateEnv`, `Credentials` and the test helpers each carry an `@example` showing the file it lives in, which `npx webjs source <Name>` prints. The `createAuth` example imports `AuthError` from `@webjsdev/server`.

## Fixes

- **`cookies().delete(name, { path, domain })` clears the cookie on that path** ([#1695](https://github.com/webjsdev/webjs/pull/1695)) [`7d949d22f`](https://github.com/webjsdev/webjs/commit/7d949d22f)
  * The options were ignored, so the cookie was only ever cleared on `/`. A `maxAge` or `expires` passed in the options no longer keeps the cookie alive.
- **A CSRF 403 names its cause** ([#1695](https://github.com/webjsdev/webjs/pull/1695)) [`7d949d22f`](https://github.com/webjsdev/webjs/commit/7d949d22f)
  * Form and RPC refusals say why (for example an `Origin` that does not match the request's host) and how to fix it, echoing only the cleaned-up origin. The check itself is unchanged.
