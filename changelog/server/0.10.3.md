## Fixes

- **`webjs check` skips a nested package with its own `package.json`** ([#1701](https://github.com/webjsdev/webjs/pull/1701)) [`164aeb9cf`](https://github.com/webjsdev/webjs/commit/164aeb9cf)
  * A folder below the app root with its own `package.json` is a separate package, such as an Expo app in `mobile/` beside an `api` backend. The check walked it as app code, so `no-foreign-framework-import` failed on its React imports and nothing could exclude it.
  * The check now skips that folder and everything under it, as it skips `node_modules`. The `package.json` at the app root is never a boundary, and the router, action and component scans are unchanged.
