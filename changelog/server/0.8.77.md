## Fixes

- **keep the preload of a lazy component imported with bindings** ([#1548](https://github.com/webjsdev/webjs/pull/1548)) [`cff25fe0`](https://github.com/webjsdev/webjs/commit/cff25fe0)
  A `static lazy` component that some module imports with bindings keeps its
  `modulepreload` hint again. That import loads it eagerly whatever the class
  says, so it is now treated as eager everywhere instead of losing its preload
  and being discovered level by level.
