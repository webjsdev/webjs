- **fail fast when the dev or start port is taken, and stop Bun sharing it** ([#1531](https://github.com/webjsdev/webjs/pull/1531)) [`8e5ba3c6`](https://github.com/webjsdev/webjs/commit/8e5ba3c6)
  A second `webjs dev` or `webjs start` on a port another server already listens on now stops at once with `port 8080 is already in use by PID 1234 (<command>)` and exit code 98, on Node and Bun alike, and the dev supervisor no longer retries it. On Bun, `Bun.serve({ development: false })` turns SO_REUSEPORT on by default, so the second server used to bind silently and the kernel split the requests between the two, leaving a stale server answering a share of them with old code. The Bun listener now passes `reusePort` explicitly; `WEBJS_REUSE_PORT=1` still shares a port on purpose, on both runtimes.
  
  A `--runtime bun` scaffold also stops naming npm and node in its remaining hints: the closing banner and the gallery reset script say `bunx webjsdev ui add`, the pre-commit hook and .gitignore comments say `bun run`, and the secret hints in .env.example and compose.yaml use `bun -e`.
