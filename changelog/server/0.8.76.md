## Features

- **keep static lazy components lazy when a module imports them** ([#1525](https://github.com/webjsdev/webjs/pull/1525)) [`502758b1`](https://github.com/webjsdev/webjs/commit/502758b1)
  `static lazy = true` now holds when another module imports the component
  for registration. The server keeps the import, so SSR renders the component
  and knows it is lazy, and the browser copy of the importer serves that
  side-effect import as an `observeLazy` registration. The module loads the
  first time an element with its tag is visible: a hidden tab panel when it
  shows, a dialog's content when it opens, an element a client render adds
  later. Preload hints skip the lazy component and anything reachable only
  through it. A binding import stays eager, and browser tests get every import
  as written. The lazy loader keeps one MutationObserver for the page.
