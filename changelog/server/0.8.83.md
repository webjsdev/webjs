## Features

- **keep typed form values across a failed form-action re-render** ([#1582](https://github.com/webjsdev/webjs/pull/1582)) [`9601f96c`](https://github.com/webjsdev/webjs/commit/9601f96c)
  On a failure re-render, `actionData.values` now carries every submitted
  text field, with the action's own `values` on top. So
  `value=${actionData?.values?.x}` refills a field the action never echoed,
  with JavaScript off as well as on.
