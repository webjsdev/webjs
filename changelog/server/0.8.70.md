## Fixes

- **webjs dev lets an idle host sleep while a dev tab is open** ([#1512](https://github.com/webjsdev/webjs/pull/1512)) [`7ac0f626`](https://github.com/webjsdev/webjs/commit/7ac0f626)
  The live-reload stream no longer sends a keepalive every 25 seconds and is
  held open only while a tab showing the app is visible; showing the tab
  reconnects, and an edit made meanwhile reloads the page. A dropped stream
  is retried with backoff. For hosts that count an open request as activity,
  `webjs.dev.reloadIdle` (or `WEBJS_DEV_RELOAD_IDLE`, seconds, off by
  default) also closes it after that long with no edit and no interaction,
  reopening on the next interaction or an embed-bridge `resume`.
- **route handlers rank by the same specificity as pages** ([#1511](https://github.com/webjsdev/webjs/pull/1511)) [`4c881953`](https://github.com/webjsdev/webjs/commit/4c881953)
  A catch-all `route.ts` such as `api/auth/[...path]` no longer answers for
  a more specific sibling such as `api/auth/callback/github`.
