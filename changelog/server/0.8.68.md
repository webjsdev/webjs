## Features

- **dev embed bridge for apps previewed in an iframe** ([#1501](https://github.com/webjsdev/webjs/pull/1501)) [`a2e75796`](https://github.com/webjsdev/webjs/commit/a2e75796)
  With `WEBJS_EMBED_ORIGINS` set under `webjs dev`, the listed parent
  origins may frame the app (`X-Frame-Options` is dropped and
  `frame-ancestors` widened for them) and every document carries a small
  nonce-signed script that posts `ready`, `navigate`, `console`, `error`,
  `network`, `server-error` and `select` messages to the parent and takes
  `navigate`, `reload` and `inspect` commands from it. Unset, and under
  `webjs start`, nothing changes.
- **dev source locations on rendered elements** ([#1502](https://github.com/webjsdev/webjs/pull/1502)) [`fe1a2ac8`](https://github.com/webjsdev/webjs/commit/fe1a2ac8)
  With `WEBJS_SOURCE_LOCATIONS=1` under `webjs dev`, every element opening
  tag in the app's `html` templates carries
  `data-webjs-src="<app-relative-file>:<line>"`, in SSR output and client
  renders alike, so a hosting tool can map a clicked element to its source line.

## Fixes

- **carry redirectTo through the OAuth sign-in round trip** ([#1497](https://github.com/webjsdev/webjs/pull/1497)) [`22cde337`](https://github.com/webjsdev/webjs/commit/22cde337)
  `createAuth`'s OAuth sign-in now honours `redirectTo` from the form body,
  the query or `signIn()`, keeps it in a short-lived signed cookie across the
  provider round trip, and lands on it after the callback. Only a same-origin
  local path is accepted; anything else is dropped, and a posted credentials
  `redirectTo` goes through the same check.
- **a fresh scaffold passes its own CI on day one** ([#1496](https://github.com/webjsdev/webjs/pull/1496)) [`10228abc`](https://github.com/webjsdev/webjs/commit/10228abc)
  The config validator and the published JSON Schema accept the
  `webjs.audit` block the scaffold now writes.
