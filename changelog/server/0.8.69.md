## Features

- **configure the dev embed bridge and source locations in webjs.dev** ([#1505](https://github.com/webjsdev/webjs/pull/1505)) [`b3801234`](https://github.com/webjsdev/webjs/commit/b3801234)
  `"webjs": { "dev": { "embedOrigins": [...], "sourceLocations": true } }`
  turns on the dev embed bridge and dev source locations from `package.json`,
  validated by the schema. Both stay off by default and are ignored by
  `webjs start`. A set `WEBJS_EMBED_ORIGINS` replaces the list, and
  `WEBJS_SOURCE_LOCATIONS=1` or `0` wins either way for one run.
