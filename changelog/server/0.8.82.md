## Fixes

- **treat arrow bodies and parameter defaults as declarations** ([#1568](https://github.com/webjsdev/webjs/pull/1568)) [`b56a2ad9`](https://github.com/webjsdev/webjs/commit/b56a2ad9)
  An expression-bodied arrow (`export const usd = (m) => Math.round(m) /
  MICROS`) and a call in a function parameter default (`function
  relativeTime(when, now = Date.now())`) are declarations, not code that runs
  at module load, so the elision analyser no longer ships a page that imports
  helpers written that way, or its import graph.
