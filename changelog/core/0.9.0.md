## Migrating from 0.8

- **A reactive property's attribute is Lit's lowercase name.** `isOpen` is observed and reflected as `isopen`, as in Lit. The kebab name (`is-open`) is still read, but reflection writes the lowercase one; set `attribute: 'is-open'` on the property to keep the old name.
- **Pages, layouts and boundaries never load in the browser.** Only components and `instrumentation-client` do, as with Next.js server components. Move browser code that sat at a page's or layout's module scope (an event listener, a client-router import, setup run by a side-effect import) into a component or `instrumentation-client.ts`. `webjs status` and `webjs doctor` flag code that looks meant for the browser.
- Lit's `static properties` plus `declare` works again beside the `WebComponent({ ... })` factory, so no change is needed for code written either way.
