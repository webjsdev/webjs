## Fixes

- **a signal read twice then once keeps re-rendering its component** ([#1509](https://github.com/webjsdev/webjs/pull/1509)) [`907195ab`](https://github.com/webjsdev/webjs/commit/907195ab)
  A component kept depending on a signal but stopped re-rendering when it
  changed, whenever one render read that signal twice and a later render read
  it once, or two reads swapped order. The live dependency edge is now
  reference counted per read, so it drops only when the last read goes.
- **webjs dev lets an idle host sleep while a dev tab is open** ([#1512](https://github.com/webjsdev/webjs/pull/1512)) [`7ac0f626`](https://github.com/webjsdev/webjs/commit/7ac0f626)
  The `WebjsConfig` type gains `dev.reloadIdle`.
