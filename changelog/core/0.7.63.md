## Breaking

- **omit a null or undefined attribute hole in SSR, matching the client** ([#1574](https://github.com/webjsdev/webjs/pull/1574)) [`2a9613cf`](https://github.com/webjsdev/webjs/commit/2a9613cf)
  A plain attribute hole (`attr=${value}`) now follows one rule on the server
  and the client. `null` and `undefined` omit the attribute, so
  `aria-current=${active ? 'page' : null}` no longer serves `aria-current=""`.
  `false` omits it too, except on an `aria-*` attribute, where both renderers
  write `"false"`. Markup changes: the server no longer emits `attr=""` or a
  non-aria `attr="false"`, and the client now writes `aria-x="false"` instead
  of removing it. A bound form's `method=${null}` is no longer refused; the
  framework supplies `method="post"`. Quoted and mixed holes are unchanged.
