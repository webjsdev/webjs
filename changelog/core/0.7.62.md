## Features

- **complete the SEO metadata surface for search and share** ([#1565](https://github.com/webjsdev/webjs/pull/1565)) [`b8419840`](https://github.com/webjsdev/webjs/commit/b8419840)
  SITE_URL now sets the default metadataBase, which gives every page a
  canonical and og:url; og:title / og:description / og:type and twitter:card
  are filled in from the page; the nearest opengraph-image / twitter-image
  route is linked as the share image; openGraph and twitter accept Next's
  shapes (images arrays and objects, siteName, article fields); metadata
  routes receive { request, url, siteUrl, pages } and may return Next's
  sitemap array or robots object; pages() lists every static page plus
  dynamic pages exporting generateSitemapParams(), leaving out noindex
  pages; robots() joins sitemap() and sitemapIndex().
