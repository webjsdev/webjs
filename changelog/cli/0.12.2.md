## Features

- **`webjs verify`** ([#1698](https://github.com/webjsdev/webjs/pull/1698)) [`1824e0eaa`](https://github.com/webjsdev/webjs/commit/1824e0eaa)
  * Whether the app works, in one call: `webjs check` and `webjs typecheck` in parallel, then `webjs test`, then the app's `webjs.dev.before` steps and an in-process boot that requests every page and GET route needing no parameter. No dev server to start or stop. A passing step prints one line and a failing one the tail of its output; every step runs even after a failure.
- **A minimal scaffold** ([#1698](https://github.com/webjsdev/webjs/pull/1698)) [`1824e0eaa`](https://github.com/webjsdev/webjs/commit/1824e0eaa)
  * `webjs create` no longer pre-installs UI kit code (the first `webjs ui add` writes `lib/utils/cn.ts`), ships no theme toggle (dark mode follows the OS) and no `instrumentation.ts`.
  * The full-stack app has no example module: `modules/` ships empty, and `AGENTS.md` lays out a module (`actions/`, `queries/`, `components/`, `utils/`, `types.ts`, its tests) and names the `modules`, `testing` and `progressive-enhancement` guides. The api template keeps its users endpoints, named as an example to replace.
