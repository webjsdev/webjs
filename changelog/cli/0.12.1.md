## Features

- **`webjs stop`** ([#1695](https://github.com/webjsdev/webjs/pull/1695)) [`7d949d22f`](https://github.com/webjsdev/webjs/commit/7d949d22f)
  * Stops the app's running `webjs dev` (through its supervisor, so the server and the `dev.parallel` tasks go together) or `webjs start`, from anywhere inside the app. It finds the server through a record under `.webjs/` that follows the port actually bound (`--port 0`, a `.env` `PORT` edit), is never overwritten by a second server that fails to bind, is taken over by a second server once the first exits, and is checked against the process start time so a reused pid is never signalled.
  * `webjs status` resolves the app root from a subdirectory too.
  * The scaffold's `AGENTS.md` says in four lines what each shipped hook does, and the scaffold notes that Drizzle 1.0's relational queries take objects and that SQLite transactions take a synchronous callback.
