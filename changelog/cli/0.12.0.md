## Migrating from 0.11

- **`webjs create` makes a minimal app.** It emits a layout, a home page, a theme toggle, the database wiring, one example feature module (`modules/users/`, to copy and then delete) and an `AGENTS.md` carrying the WebJs brief and a section the agent keeps about the app. The feature gallery and the agent skill no longer ship in a new app; the gallery lives at gallery.webjs.dev.
- **`NODE_ENV` defaults per command**, only when it is unset: development for `webjs dev`, production for `webjs start` (as `next start`), test for `webjs test` (as Jest). A process a test spawns inherits test.
- `npx webjs source` with no name lists what WebJs provides by need, and `--pkg <name>` lists one package's source.
- New apps pin Drizzle `1.0.0-rc.5` exactly.
