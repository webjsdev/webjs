## Fixes

- **a fresh scaffold passes its own CI on day one** ([#1496](https://github.com/webjsdev/webjs/pull/1496)) [`10228abc`](https://github.com/webjsdev/webjs/commit/10228abc)
  A new app is green on its first `webjs ci`, including right after
  `gallery:clear`. `webjs test --browser` passes with a note when there
  are no browser tests yet. `--db postgres` apps get a Postgres service in
  `compose.yaml` and in the CI workflow. The audit step runs the new
  `webjs audit`, which honours a reviewable `webjs.audit.ignore` allowlist
  for advisories with no patched release, and the scaffold pins a fixed
  `basic-ftp`. UI scaffolds declare `tailwindcss` directly, and
  `webjs doctor` warns when an app inside a workspace carries its own
  `overrides`.
- **webjs ui add uses bun for bun.lock and workspace-root lockfiles** ([#1500](https://github.com/webjsdev/webjs/pull/1500)) [`e7902d59`](https://github.com/webjsdev/webjs/commit/e7902d59)
  When `webjs create` is not invoked through a package manager, the
  enclosing project's lockfile (including `bun.lock`) picks the installer.
