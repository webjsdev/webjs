## Features

- **Lookups answer file-convention and pattern questions in one call** ([#1695](https://github.com/webjsdev/webjs/pull/1695)) [`7d949d22f`](https://github.com/webjsdev/webjs/commit/7d949d22f)
  * The `source` tool (and `npx webjs source`) resolves a file-convention name such as `not-found`, `middleware.ts`, `route.ts` or `loading` to a short routing guide, and `uploads`, `authentication`, `testing`, `data-flow` and others to their own guides. Real exports (`notFound`, `redirect`, `route`) still return their declaration, and `route` / `middleware` point at the routing guide.
  * Guides are returned only for a lookup by name; nothing lists them up front, in the catalogue or the tool description, so an agent does not read them before it needs them.
