## Features

- **The class helpers with a shadcn name take `className`** ([#1698](https://github.com/webjsdev/webjs/pull/1698)) [`1824e0eaa`](https://github.com/webjsdev/webjs/commit/1824e0eaa)
  * `buttonClass({ variant: 'link', className: 'mt-2' })` merges the class through `cn()`, as shadcn's `buttonVariants` does, and so do the 16 other helpers that have a shadcn alias (`badgeClass`, `toggleClass`, `tabsListClass`, `itemClass` and the rest). Without a `className` every helper returns exactly what it did.
  * `lib/utils.ts` (copied to an app as `lib/utils/cn.ts`) is about half the size: its commentary on the class merger moved to the package docs, and its code is unchanged.
