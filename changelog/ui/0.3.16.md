## Fixes

- **webjs ui add uses bun for bun.lock and workspace-root lockfiles** ([#1500](https://github.com/webjsdev/webjs/pull/1500)) [`e7902d59`](https://github.com/webjsdev/webjs/commit/e7902d59)
  `webjs ui add` installs the kit's dependencies with the project's own
  package manager. It now recognises Bun's text `bun.lock` as well as the old
  `bun.lockb`, looks for a lockfile in the current folder and then each parent
  up to the workspace root, and falls back to `npm_config_user_agent` before
  npm, so a Bun project no longer gets a stray `package-lock.json`.
