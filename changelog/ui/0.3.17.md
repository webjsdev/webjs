## Features

- **add empty, spinner and field components** ([#1571](https://github.com/webjsdev/webjs/pull/1571)) [`128fadbb`](https://github.com/webjsdev/webjs/commit/128fadbb)
  Three new Tier-1 components with shadcn parity. `empty` is the empty state
  for a list or region (`emptyClass`, `emptyHeaderClass`,
  `emptyMediaClass({ variant })`, `emptyTitleClass`, `emptyDescriptionClass`,
  `emptyContentClass`). `spinner` is a busy indicator (`spinnerClass` plus
  `spinner({ class, label, decorative })`, an inline SVG with `role="status"`).
  `field` is the form-field layout system (`fieldSetClass`, `fieldLegendClass`,
  `fieldGroupClass`, `fieldClass({ orientation })`, `fieldContentClass`,
  `fieldLabelClass`, `fieldTitleClass`, `fieldDescriptionClass`,
  `fieldErrorClass`, `fieldSeparatorClass`, `fieldSeparatorContentClass`). Add
  them with `webjs ui add empty spinner field`.
